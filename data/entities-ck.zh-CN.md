# CK 实体层与制图说明

CK 地图的 Game 层请使用 `entities-ck.png`。

| 格位 | 用途 |
| --- | --- |
| 1-4 | 实心、死亡、不可钩、水面碰撞 Tile |
| 6、160、176-188 | 补给、反坦克、防空、职业、限制与水下武器 Tile；186-188 分别为鱼叉、箭矢和飞镖星 |
| 192-202 | 标准出生、队伍出生、旗帜与拾取实体 |
| 197-200 | 生命补给、弹药补给、烟雾发射器、水面武器启用 |
| 214-223、230-239、246-255 | 中立、红队、蓝队的直升机、战机、坦克、汽车、潜艇、战舰和迷你载具出生点 |
| 240 | DDNet Door；必须放在 Switch 层并设置 Number |

红、蓝载具出生点已有队色区分；中立载具保留原色。

## 出生点与基地旗帜

`ENTITY_SPAWN_RED` 表示地图的物理进攻方出生区，
`ENTITY_SPAWN_BLUE` 表示物理防守方出生区。第一回合红队使用红方出生区；
第二回合蓝队进攻时使用红方出生区，红队改用蓝方出生区。

Game 层的 Red/Blue Flagstand 是两侧基地旗帜。物理进攻侧旗帜是基地，
物理防守侧旗帜只能在最终阶段被进攻方夺取。

## 据点、门、CP 旗帜与传送

1. 在 Switch 层放置 `TILE_SWITCHOPEN`，以 Number `1-16` 定义 CP。
2. 在 Switch 层放置 Door（格位 240），用相同 Number 表示通往该 CP 的门。
3. 连续铺设相同 Number 的 Door Tile。横向、纵向或斜向的连续砖块会按直线段合并为一条激光，并延伸到首尾砖块的外边缘；因此砖块轨迹能精确控制门的长度和形状，同时不会为每格重复生成激光对象。孤立的单个 Door Tile 无效。
4. Door `Number N` 在 CP `N` 因任一前驱据点被攻下而变为可进攻时打开；CP `N` 被攻下后保持打开。Door `Number 255` 仅在最终夺旗阶段开启。
   门关闭时只阻挡进攻方角色和载具；防守方角色可直接通过。双方的弹药与载具武器仍会被关闭的门阻挡，进攻载具不能绕过关闭的战线门。
5. CP 状态旗使用 Switch 层的任一标准 Flagstand，并设置为相同 Number。它只显示当前控制该 CP 的玩家队伍颜色，不能拾取。
6. Tele In 按入口方区分：`1-16` 是进攻方入口，对应 CP `1-16`；`17-32` 是防守方入口，同样对应 CP `1-16`。Tele Out 是共用出口，使用 CP 的 Number `1-16`；两个阵营的同一 CP 入口都会到达该出口。Tele In 按据点实际归属开启：据点属于防守方时仅防守方入口可用；被进攻方完整占领后仅进攻方入口可用；反攻夺回后切回防守方。因此同一 CP 同时只会有一个队伍的入口可用。连续铺设的同 Number Tele In Tile 会合并为一条覆盖首尾砖块外边缘的完整激光，入口中的每一格都能触发传送。传送是可选捷径，载具不能使用传送。
   若启用的 Tele In 与关闭 Door 重叠，则只显示 Door 的完整激光；该 Door 打开后才显示短 Tele 标识，避免两条门线重叠。

Switch 的 CP、Door、CP 旗帜和 Tele 必须共用同一个 Number，服务器会校验其是否对应有效 CK 节点。

## 对局流程与占领速度

每张地图固定进行两回合：先由红队进攻，再由蓝队从物理红方出生区进攻。进攻方占领 `goals` 中所有据点后，进入最终阶段；此时夺取防守旗帜并送回进攻基地，即为本回合唯一胜利条件。时间结束时，依次按已占领据点数、最深推进层级和当前据点进度比较两队的进攻成绩。

据点内敌我同时存在时，进度冻结；据点空置 3 秒后才缓慢回退。单人完整占领时间按非观战玩家总数动态调整，为 16–30 秒；两名同队玩家占点为 1.5 倍速度，三人及以上最高 2 倍。防守方反攻使用相同规则。

## 地图配置

每张战斗地图必须有同名配置：`maps/<地图名>.battle.json`。`modes` 决定地图可用于 `openbattle`、`ck` 或两者；CK 地图额外使用 `ck` 段定义据点图。

```json
{
  "version": 1,
  "modes": ["openbattle", "ck"],
  "ck": {
    "points": [
      { "number": 1, "label": "A", "from": [] },
      { "number": 2, "label": "B", "from": [1] },
      { "number": 3, "label": "C", "from": [2] },
      { "number": 4, "label": "C-SideA", "from": [2] },
      { "number": 5, "label": "D", "from": [3, 4] }
    ],
    "goals": [5]
  }
}
```

`from` 是直接前驱，采用“任一满足即可”的关系。上例中攻下 C 或 C-SideA 任一据点后都可进攻 D；防守方仍拥有任一分支据点时可反攻 B。攻下节点会将所有上游前驱归进攻方，反攻节点会将所有下游后继归防守方。`goals` 中全部节点被攻下后，才进入最终夺旗阶段。

支持任意无环据点图，但建议以主线配少量侧路为主，玩家可以通过 `/objective` 直接查看当前可进攻和可反攻据点。

缺少配置、模式不匹配、Number 不一致、图存在环、节点不可达或终点非法时，CK 会拒绝当前回合并输出原因。

旧 Battlefield 的单格门、旧据点线、旧据点目的地和 A-C 旧据点 Tile 不用于 CK。
